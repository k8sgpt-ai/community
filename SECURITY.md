# Security Policy

Security reports for the k8sgpt project, including this repository, are handled by the k8sgpt Security Response Team.

Follow the [k8sgpt security policy](https://github.com/k8sgpt-ai/k8sgpt/blob/main/SECURITY.md). Do not report vulnerabilities through public GitHub issues, discussions, pull requests, or Slack.

Report privately through [GitHub private vulnerability reporting](https://github.com/k8sgpt-ai/k8sgpt/security/advisories/new) or by email to contact@k8sgpt.ai with `[SECURITY]` in the subject line.
